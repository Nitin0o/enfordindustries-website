# ENFORD Industries website
Static corporate website intended for GitHub Pages.

## Main areas
- `index.html`: homepage
- `catalogue.html`: searchable product catalogue
- `products/`: individual product pages
- `categories/`: category landing pages
- `products.json`: structured product data
- `product-master.csv`: editable product master
- `brand/enford-logo.svg`: approved ENFORD logo
- `sitemap.xml` and `robots.txt`: search engine discovery

## Publishing
1. Open repository **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Set branch to `main`, folder to `/(root)`, then save.
4. Test the GitHub Pages URL before adding the custom domain.
5. Add `www.enfordindustries.com` in GitHub Pages custom domain settings.
6. Follow the exact DNS instructions GitHub shows in GoDaddy.
7. Preserve existing Zoho MX, SPF, DKIM and DMARC records. Do not replace email DNS records while setting up the website.
8. Enable HTTPS after GitHub verifies the domain.

## Product data
The product master is an initial starter directory. Listing means the product is open for a sourcing enquiry; it does not mean current stock, a confirmed supplier appointment, guaranteed availability or in-house manufacture. Confirm the exact grade, specification, documentation, compliance position, source and availability for each enquiry.
